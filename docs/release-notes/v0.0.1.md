utterpy 0.0.1 is the first release of the Python binding for utter, the pure-Rust streaming decoder for Vosk models. The surface is the vosk wheel's: `Model`, `KaldiRecognizer`, `AcceptWaveform`, `PartialResult`, `Result` and `FinalResult`, with the same JSON shapes, so a host swaps the import and keeps its code.

## Added

`SetEndpointBound(trailing_ms, extending_veto_nats)`: a host endpoint bound, a final once the trailing silence reaches the bound, with a veto for a rival whose word is still extending. `SetEndpointFloorMargin(margin_db)`: a margin in dB over the reported floor within which the bound reads a wordless path as silence.

Every final names the endpoint rule that closed it, and each word carries `stable_ms`, `energy_dbfs` and sample offsets beside the vosk fields.

`UTTER_REVISION`: the utter commit the wheel was built from.

## Wheels

Linux x86_64 and aarch64 (manylinux 2_28 and musllinux 1.2), Windows x64 and arm64, macOS x86_64 and arm64. One wheel per platform serves Python 3.9 and later through the stable ABI. The module ships a stub and py.typed, checked against the binary by stubtest. The wheel has no runtime dependencies.

Every wheel and the sdist carry a build-provenance attestation, and the release attaches the Sigstore bundle so a wheel verifies offline:

```bash
gh attestation verify utterpy-0.0.1-cp39-abi3-manylinux_2_28_x86_64.whl --bundle utterpy-v0.0.1.sigstore.json --owner pyscape
```
