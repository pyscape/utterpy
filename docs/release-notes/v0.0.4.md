utterpy 0.0.4 carries utter 0.0.4, which fixes the floor margin of 0.0.3 so that it does not cut a quiet word after a pause. The binding is unchanged; with the margin unset the output is identical to 0.0.3.

## Fixed

The floor margin on the host's endpoint bound now reads no span shorter than the bound itself. In 0.0.3 a trailing `[speech]` entry or a rival's extending word was judged against the floor at any length, and the first frames of a quiet word after a pause sit near the floor on any microphone: the margin waived the veto, the bound fired between the two words of a command, and the second word came back late as short grammar words. A span at least the bound's length is seconds long on a cold room and a few frames at an onset, so the wordless closes stay and the onsets do not. The measurement is in utter's [release notes](https://github.com/pyscape/utter/blob/main/docs/release-notes/v0.0.4.md) and TD-12.

## Install

```bash
pip install utterpy
```

Wheels for Linux x86_64 and aarch64 (manylinux 2_28 and musllinux 1.2), Windows x64 and arm64, and macOS x86_64 and arm64, Python 3.9 and later through the stable ABI. Every wheel carries a build-provenance attestation, and the release attaches its Sigstore bundle:

```bash
gh attestation verify utterpy-0.0.4-cp39-abi3-manylinux_2_28_x86_64.whl --bundle utterpy-v0.0.4.sigstore.json --owner pyscape
```
