# Test clips

Three one-second recordings of one speaker from the Google Speech
Commands dataset v0.02, `012c8314_nohash_0` under `yes`, `no` and
`stop`, 16 kHz mono 16-bit. The dataset is released under the
[Creative Commons BY 4.0](https://creativecommons.org/licenses/by/4.0/)
license; see <https://arxiv.org/abs/1804.03209>.
